Drive CLI

Drive CLI is a personal Google OAuth application used with rclone on the owner's computer to back up and organize the owner's Google Drive files.

It is not a public file-sharing service. Authorization credentials stay on the owner's computer, and transfers go directly between that computer and Google Drive. This website does not receive Drive files or OAuth credentials.

The application requests Google Drive file-management access so the owner can list, upload, download, move, rename, and delete their own files when requested.
